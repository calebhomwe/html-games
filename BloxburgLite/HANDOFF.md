## Key design decisions already made (do not re-litigate)
- Input split: play mode = pointer-locked mouse orbit + WASD; build mode = MMB-drag orbit, WASD disabled, RMB delete, LMB place, R rotate, scroll cycle item, Tab toggles mode
- Movement: walk 3 u/s, run 6 u/s, no jump; camera 6u @ 35 deg pitch, 10-70 deg clamp
- Grid: tiles (0..9)^2, rot in {0,90,180,270}, min-corner anchoring, footprint swaps on 90/270
- Catalog: chair $50 1x1, table $120 2x2, bed $300 2x3, sofa $250 3x1, lamp $75 1x1 (full set = $795 <= $1000 start)
- Money: start $1000, deduct on place, refund on delete
- Save: write-through autosave JSON {version, money, plot, items} at persistentDataPath, auto-load on boot, corrupt save = fresh state never crash
